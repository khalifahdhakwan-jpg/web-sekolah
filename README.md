# 🎓 Sistem Informasi Sekolah Berbasis Web (SMAN 1 Coding)

Project ini adalah Sistem Informasi Sekolah komprehensif yang dibangun menggunakan PHP Native dan MySQL. Sistem ini memisahkan antara halaman publik untuk pengunjung dan ruang kendali (Dashboard Admin) untuk mengelola data operasional sekolah secara dinamis.

## 🚀 Fitur Utama

**Sisi Publik (Frontend):**
- Landing Page & Profil Sekolah
- Direktori Data Guru & Siswa
- Jadwal Pelajaran Dinamis
- Publikasi Berita / Pengumuman Sekolah
- Galeri Dokumentasi Kegiatan

**Sisi Admin (Backend):**
- Autentikasi Admin yang aman (menggunakan Password Hashing & Session)
- Dashboard Statistik Real-time
- Manajemen Data Kelas (CRUD)
- Manajemen Data Guru & Siswa (CRUD + Relasi + Upload Foto)
- Manajemen Jadwal Pelajaran (Multi-Relasi)
- Manajemen Berita (CRUD + Auto-Slug + Upload Cover)
- Manajemen Galeri (Grid Layout + Image Upload)

## 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, Bootstrap 5 (Responsive Mobile-First)
- **Backend:** PHP 8.x (Native Procedural)
- **Database:** MySQL / MariaDB
- **Tools:** VS Code, Laragon, phpMyAdmin
